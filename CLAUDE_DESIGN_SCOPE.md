# Grew UI redesign scope

Brand: **그루 / Grew**.

When redesigning the app UI, preserve application behavior and data structures. Focus on the general app experience: onboarding/login, Today, search, scrap, detail, MY, profile/settings, cards, buttons, navigation, typography, spacing, hierarchy, and color system.

The forest visualization (tree art, visitors, decorations, placement logic, zoom behavior) is a separate visual system. Do not redesign or remove it unless explicitly requested.

Useful files for UI work:
- `index.html`
- `css/styles.css`
- `js/03-core.js`
- `js/08-cloud-storage.js` (contains much of the current screen-rendering code despite the filename)
- `js/11-onboarding.js`
- `js/01-app-brand.js`

Forest-specific files:
- `js/02-forest-art.js`
- `js/09-forest.js`
- `assets/images/trees/`
- `assets/images/forest/`
